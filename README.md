# Máxima Assessoria

Site institucional da Máxima Assessoria, desenvolvido com Next.js e preparado
para publicação na Vercel.

## Requisitos

- Node.js `>=22.13.0`
- pnpm

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Build de produção

```bash
pnpm build
pnpm start
```

## Publicação na Vercel

Importe este repositório na Vercel. O framework Next.js e os comandos de
instalação e build serão detectados automaticamente.
